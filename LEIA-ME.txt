COMO INSTALAR

No computador, faça download/clonagem do repositório:
  https://github.com/jesusneresberg-ux/Leitor-IA

Coloque upgrade_lume.py em qualquer pasta e execute no terminal:
  python upgrade_lume.py /caminho/para/Leitor-IA

Requer acesso à internet na instalação para obter os dois arquivos da versão 4.10.38 do PDF.js, que passarão a ficar no próprio projeto. Depois execute:
  cd /caminho/para/Leitor-IA
  git add index.html manifest.webmanifest service-worker.js assets/pdfjs
  git commit -m "Atualiza LUME: leitura limpa e offline"
  git push

Se estiver usando GitHub Pages ou PWA/APK WebView, abra o aplicativo uma vez conectado à internet após publicar a atualização, aguarde o cache instalar e então teste em modo avião.

IMPORTANTE: para esta mudança aparecer no app Android, o APK/WebView deve carregar a versão publicada no GitHub Pages, ou precisa ser recompilado e reinstalado com estes arquivos. A atualização não foi publicada nem compilada automaticamente.
