LEITOR IA — VERSÃO 1

Objetivo
Leitor de PDF focado em celular e leitura vertical 9:16.

Já incluído
- Abrir PDF local.
- Extração de texto com PDF.js.
- Modo leitura limpa.
- Heurística para reduzir cabeçalhos, rodapés e números de página.
- Referências compactas com painel ampliado.
- Alternância para página original.
- Ajuste de fonte e espaçamento.
- Anotações por página salvas no aparelho.
- Modo audiobook usando as vozes disponíveis no navegador/dispositivo.
- Controle de velocidade, pausa e parada.
- Painel de IA preparado para resumo, explicação, perguntas e Q&A.
- Pesquisa no Google.
- Modo escuro.
- PWA instalável.

Próximas integrações
1. IA real: backend seguro + provedor de IA.
2. Voz neural premium.
3. OCR para PDFs digitalizados como imagem.
4. Sincronização em nuvem.
5. Biblioteca de documentos e progresso de leitura.
6. Marcações/highlights persistentes.

Observação
O app usa PDF.js por CDN. Para funcionamento totalmente offline, a próxima versão pode incorporar os arquivos do PDF.js no próprio projeto.
